Process Reflection

So far, I’ve noticed that I like to use multiple pages within one HTML website. To me, it feels like opening teleportation doors. It creates a kind of perceptual experience that feels different from a single-page website. For example, in my “Journal a Walk” project, I used different links to represent different stops along my walk. In my “Recipe” project, I used links to represent a mental map of thoughts, with one idea leading to the next.

After noticing this tendency, I tried working with a single page in my third project. I think it creates a different feeling while still keeping my own voice. So far, I feel that I’ve built a foundation for structuring HTML and styling it with CSS. I still need to practice using different elements, especially layout and positioning. Next, I want to experiment more with interactive elements and explore how to make my websites more visually engaging.
